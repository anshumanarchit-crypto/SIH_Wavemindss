# classifier_output.json Schema Documentation

**Owner:** Harsh (Stage 5 Baseline Classifier) / Archit (Adapter Layer)  
**Consumer:** Archit (N5 Hybrid Consensus Engine)  
**Schema Version:** `1.0.0`

---

## 1. Overview
The `classifier_output.json` contract provides the statistical probability distribution over candidate modulation classes generated by the trained RandomForest classifier from physical signal-derived features.

---

## 2. Field Specifications

| Field | Type | Description | Constraints / Allowed Values |
| :--- | :--- | :--- | :--- |
| `schema_version` | `string` | Semantic contract version | Strictly `"1.0.0"` |
| `capture_id` | `string` | Capture identifier matching analysis | Non-empty string |
| `window_id` | `string` / `integer` | Temporal sub-window index | Identifier of analysed sub-window |
| `ml_prediction` | `string` | Highest-probability modulation label | Must be a key in `ml_probabilities` |
| `ml_probabilities`| `object` | Mapping of class name to probability | Class names $\to [0.0, 1.0]$ |
| `calibrated_probability` | `float` / `null` | Platt / Isotonic calibrated probability | $[0.0, 1.0]$ or `null` |
| `model_version` | `string` | Release tag of trained model artifact | e.g. `"rf-baseline-1.0.0"` |
| `feature_vector_used` | `object` | Name-to-value map of features fed | Features: cumulants, SNR, EVM, cluster stats |

---

## 3. Invariants
- `ml_prediction` must be a valid member of the `ml_probabilities` dictionary.
- Probabilities must fall strictly within $[0.0, 1.0]$.
- The raw classifier probability is NEVER used directly as final decision confidence.
